**域名**: demo.hamr.top

HamR 在线演示环境提供零门槛的产品体验，用户无需本地部署即可体验五维家庭管理全流程。

## 🎯 核心职责

### 1. 零门槛体验
- 部署完整功能实例
- 无需本地安装
- 即开即用

### 2. 临时账号管理
- **邮箱快速注册**: 验证后立即可用
- **预设 Demo 账号**: demo@hamr.top / demo123
- **账号限制**:
  - 7 天有效期
  - 单用户限 1 个家庭
  - 最多 5 个成员
  - 100MB 存储空间

### 3. 示例数据
预填充 4 口之家完整脱敏数据：
- **人**: 张爸爸、李妈妈、张小明(儿子)、张小花(女儿)
- **关系图谱**: 家庭成员关系
- **日程**: 2 周日程安排
- **任务**: 20+ 待办任务
- **资产**: 房产/车辆/电器等
- **环境**: 温湿度历史数据

### 4. 自动重置
- **重置时间**: 每日凌晨 3 点
- **重置内容**: 删除临时数据，恢复初始状态
- **保留数据**: Demo 账号和示例数据

### 5. 功能引导
- **Product Tour**: 交互式引导
- **转化引导**: 引导至正式注册

### 6. 安全防护
- **IP 限流**: 10 req/min/IP
- **全局限流**: 1000 req/min
- **禁用功能**: 邮件发送、Webhook 回调

## 🚀 快速开始

### 后端启动

```bash
cd backend

# 配置环境变量
cp .env.example .env

# 初始化示例数据
cargo run --bin seed

# 启动服务
cargo run
```

### 前端启动

```bash
cd frontend

npm install
npm run dev
```
